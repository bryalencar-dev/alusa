## 🎯 Casos de Uso

### Caso 1: "Preciso criar uma nova funcionalidade"

```
1. Ler: ONBOARDING_QUICK_START.md (seção "Como Criar")
2. Copiar: QUICK_REFERENCE.md (templates)
3. Validar: ARQUITETURA_E_PADROES.md (checklist)
4. Evitar: CORREMOS_DE_ARQUITETURA.md (erros comuns)
```

### Caso 2: "Cometi um erro e preciso corrigir"

```
1. Identificar: CORREMOS_DE_ARQUITETURA.md (exemplos)
2. Entender: DIAGRAMA_ARQUITETURA.md (contexto)
3. Corrigir: ARQUITETURA_E_PADROES.md (padrão correto)
4. Validar: QUICK_REFERENCE.md (checklist)
```

### Caso 3: "Dúvida rápida durante desenvolvimento"

```
1. Consultar: QUICK_REFERENCE.md (first stop)
2. Se não resolver: ARQUITETURA_E_PADROES.md (seção específica)
```

### Caso 4: "Code review - validar PR"

```
1. Checklist: ARQUITETURA_E_PADROES.md (seção "Checklist")
2. Padrões: QUICK_REFERENCE.md (nomenclatura, estrutura)
3. Anti-patterns: CORREMOS_DE_ARQUITETURA.md (o que evitar)
```

### Caso 5: "Configurar AI assistant"

```
1. Ler: COPILOT_INSTRUCTIONS.md (regras críticas)
2. Configurar: Templates de QUICK_REFERENCE.md
3. Referenciar: ARQUITETURA_E_PADROES.md (contexto)
```
